API 开通说明

  1. ElevenLabs：打开 pricing，注册并选择含 API credits 的套餐。
  2. 进入 API Keys，新建 key；进入 Voice Library 选一个法语自然的声音，复制 voice_id。
  3. 回到本页，把 key 和 voice_id 填入，点“保存绑定”。
  4. OpenAI：打开 Billing 绑定银行卡，再到 API Keys 创建 key。OpenAI API 与 ChatGPT Plus 分开计费。

如果浏览器限制直接请求 API，可复制文本到语音平台控制台生成 mp3，再放入 audio 文件夹。
